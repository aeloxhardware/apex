# Apex — terrain de jeu

Ce dépôt est l'endroit où le moteur (`aeloxhardware/apex-engine`) et l'interface
(`aeloxhardware/apex-ui`) se rejoignent. Il ne contient le code d'aucun des deux.

Toute session qui travaille sur l'un des trois dépôts lit d'abord :
- [`integration/RULES.md`](integration/RULES.md) : règles de développement séparé et contrat ;
- [`integration/REQUESTS.md`](integration/REQUESTS.md) : demandes ouvertes entre dépôts.
